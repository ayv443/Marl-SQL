# Marl-SQL

Text-to-SQL with reinforcement learning: DPO vs GRPO vs RLOO on Qwen2.5-Coder-1.5B-Instruct + LoRA,
trained on Spider and evaluated on Spider dev, Spider-Syn, Spider-DK and BIRD dev.

- [RESULTS.md](RESULTS.md): all results in one place, with links to the files behind every number
- [text2sql-rl/](text2sql-rl/): the code ([README](text2sql-rl/README.md))
- [text2sql-rl/proof/](text2sql-rl/proof/): training logs and run records for all three models
- [text2sql-rl/evaluation/](text2sql-rl/evaluation/): evaluation results, statistics and logs
